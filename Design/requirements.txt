overview: the implementation shall allow the user to calculate area, volume, and angles of different shapes



REQ_1:
the software will allow the user to select from a list of shapes (Cuboid, Pyramid, Sphere, Cone, Tube, Disk, Snowman).
From there, depending on the selected shape the software will utilize the correct formulae to calculate the correct measurements from 
    user-input dimensions

LLR1
the software shall print all the available shape names.

LLR2
the software shall then number and list the shape names to the user as options.

LLR3
the software shall prompt the user to select a shape by entering the corresponding number.

LLR4
the software shall store this number and use it to determine which calculations and formulae to use

LLR5
the software shall restart this process if the user inputs an invalid number or character



REQ_2:
the software shall print user inputs and constrain the user inputs to between 10mm and 10000mm.
    It will then output the calculated measurements to the user.

Once the user selects a shape,

LLR6
the software shall prompt the user for length, width and height to input values for them.

LLR7
the system shall ensure that each input is greater than 9 and less than 10001 and is an integer.

LLR8
the software shall restart the process if an invalid input is detected

LLR9
the software shall return the calculated values

LLR10
the software shall ask the user if they would like to calculate another shape or terminate. Then
    the software shall restart the program if the user decides to calculate another shape.



REQ_3: #H = height, W = width, L = length
the software shall return the surface area, volume and H:W, W:L, L:H when a Cuboid is selected.

LLR11
the software shall utilise the following formulae for the Cuboid (using the user inputs):
    surface_area = 2 * (length * width + length * height + width * height)
    volume = length * width * height
    H:W ratio = height / width
    W:L ratio = width / length
    L:H ratio = length / height



REQ_4:
When a Pyramid is selected, the software shall return Volume, Base area, Long Base Triangle area, Short base triangle area, Angles of the Short Base Triangle, 
    angles of the Long Base Triangle and the sum of triangle angles for both base lengths or just 1 of them if they are
    the same.

LLR12
the software shall compare the Base length and width and find which is larger.

LLR13
the software shall utilise the following formulae for the Pyramid (using its user input Base dimensions and height) (assuming the base is rectangle, pyramid type was not specified):
    volume = (1/3) * width * length * perpendicular height
    base_area = width * length

    shorter base triangle area = (1/2) * sqrt((longer side /2)^2 + (perpendicular height)^2) * shorter base
    shorter base triangle apex angle = arctan((smaller side /2) / sqrt((smaller side /2)^2 + (perpendicular height^2)
    shorter base triangle base angle = (180 - shorter base triangle apex angle) / 2

    longer base triangle area = (1/2) * sqrt((smaller side / 2)^2 + (perpendicular height)^2) * longer side
    longer base triangle apex angle = arctan((longer side /2) / sqrt((longer side /2)^2 + (perp_height)^2))
    longer base triangle base angle = (180 - longer base tringle apex angle) / 2

LLR14
the software shall calculate the sum of the angles for both unless the base lengths are equal, in which case it will only calculate one of them.
    Using the following formulae:
    Sum of long base triangle angles* = longer base triangle base angle * 2 + longer base triangle apex angle
    Sum of short base triangle angles* = shorter base triangle base angle * 2 + shorter base triangle apex angle
    *only one will be calculated if sum of short base angles = sum of long base angles
