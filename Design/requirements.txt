LLR2

LLR3

LLR4

LLR5

LLR6

LLR7

LLR8

LLR9
the software shall ask the user if they would like to calculate another shape or terminate. Then
    the software shall restart the program if the user decides to calculate another shape.


#H = height, W = width, L = length
"the software shall return the surface area, volume and H:W, W:L, L:H when a Cuboid is selected."

LLR10
the software shall utilise the following formulae for the Cuboid (using the user inputs):

    surface_area = 2 * (length * width + length * height + width * height)
    volume = length * width * height
    H:W ratio = height / width
    W:L ratio = width / length
    L:H ratio = length / height



"When a Pyramid is selected, the software shall return Volume, Base area, Long Base Triangle area, 
    Short base triangle area, Angles of the Short Base Triangle, angles of the Long Base Triangle
     and the sum of triangle angles for both base lengths or just 1 of them if they arethe same."

LLR11
the software shall compare the Base length and width and find which is larger.

LLR12
the software shall utilise the following formulae for the Pyramid (using its user input Base dimensions and height)
    (assuming the base is rectangle, pyramid type was not specified):

    volume = (1/3) * width * length * perpendicular height
    base_area = width * length

    shorter base triangle area = (1/2) * sqrt((longer side /2)^2 + (perpendicular height)^2) * shorter base
    shorter base triangle apex angle = arctan((smaller side /2) / sqrt((smaller side /2)^2 + (perpendicular height^2)
    shorter base triangle base angle = (180 - shorter base triangle apex angle) / 2

    longer base triangle area = (1/2) * sqrt((smaller side / 2)^2 + (perpendicular height)^2) * longer side
    longer base triangle apex angle = arctan((longer side /2) / sqrt((longer side /2)^2 + (perp_height)^2))
    longer base triangle base angle = (180 - longer base tringle apex angle) / 2

LLR13
the software shall calculate the sum of the angles for both unless the base lengths are equal, in which case it will only calculate one of them.
    Using the following formulae:
    Sum of long base triangle angles* = longer base triangle base angle * 2 + longer base triangle apex angle
    Sum of short base triangle angles* = shorter base triangle base angle * 2 + shorter base triangle apex angle
    *only one will be calculated if sum of short base angles = sum of long base angles



"when a Sphere is selected, the software shall return the surface area and volume."

LLR14
the software shall utilise the following formulae for the Sphere (using its user input radius): # pi is a constant approximately equal to 3.14159

    surface area = 4 * pi * radius^2
    volume = (4/3) * pi * radius^3



"When a Cone is selected the software shall return the surface area, volume, and angle from base to concical surface"

LLR15
the software shall utilise the following formulae for the Cone (using its user input radius and height):
    surface area = pi * radius * (radius + sqrt(radius^2 + height^2))
    volume = (1/3) * pi * radius^2 * height
    angle from base to concical surface = arctan(height / radius)



"when a disk is selected, the software will return the surface area and volume"
LLR16
the software shall utilise the following formulae for the disk (using its user input radius, height and disk thickness):
    surface area = (2 * pi * radius * height + 2 * pi * (radius + disk thickness)) * height + 2 * (pi * (radius + disk thickness)^2 - pi * radius^2)
    volume = pi * (radius + disk thickness)^2 * height - pi * radius^2 * height
