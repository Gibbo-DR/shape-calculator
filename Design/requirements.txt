overview: the implementation shall allow the user to calculate area, volume, and angles of different shapes

REQ_1:
the solution will allow the user to select from a list of shapes (Cuboid, Pyramid, Sphere, Cone, Tube, Disk, Snowman).
From there, depending on the selected shape the solution will utilize the correct formulae to calculate the correct measurements from 
    user-input dimensions

the solution shall fetch all the available shape names.
the solution shall then number and list the shape names to the user as options.
the solution shall prompt the user to select a shape by entering the corresponding number.
the solution shall store this number and use it to determine which calculations and formulae to use
the solution shall restart this process if the user inputs an invalid number or character


REQ_2:
the solution shall constrain the user inputs to between 10mm and 10000mm

Once the user selects a shape,
the solution shall fetch the required inputs
the solution shall iterate through required inputs and prompt the user to input values for them, ensuring that each input is 9<x<10001 and is an integer
the solution shall then calculate the desired outputs for the selected shape.
the solution shall clean the input array and restart the process if an invalid input is detected

REQ_3:
the solution shall return the surface area, volume and H:W, W:L, L:H when a Cuboid is selected.

the solution shall utilise the following formulae for the Cuboid (using the user inputs):
    surface_area = 2 * (length * width + length * height + width * height)
    volume = length * width * height
    ratio_H_W = height / width
    ratio_W_L = width / length
    ratio_L_H = length / height

the solution shall return each of these values to the user
the solution shall ask the user if they would like to calculate another shape or terminate.
the solution shall restart the program if the user decides to calculate another shape.
